# Brassart_GD3_TP

Présentation : En cliquant sur un bouton qui apparaît sur l'écran, une compétence se lance. 
Organisation : Les principaux dossiers sont le dossier Script, où se trouve les scripts, et Import_Package, où se trouvent les VFX importées utilisables dans le projet.

Fonctionnalités : 

- Cliquer sur un bouton fait apparaître dans la console le nom de la compétence.
- Les habilités peuvent être créées rapidement grâce au Scriptable Object : "NewAbility", il faut renseigner plusieurs informations comme le nom, le préfixe, la couleur.
- Un début de système de vie est implémenter mais non intégré.
